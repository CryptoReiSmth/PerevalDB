# Pereval REST API

REST API для передачи данных о горных перевалах туристами.

Проект реализован на Django и Django REST Framework.  
API позволяет добавлять информацию о перевалах, получать данные по id, редактировать записи со статусом new, а также получать список перевалов, отправленных конкретным пользователем.

---

## Основной функционал

- Добавление нового перевала
- Сохранение координат и высоты объекта
- Сохранение информации о пользователе
- Сохранение уровня сложности по сезонам
- Загрузка фотографий
- Хранение фотографий на сервере
- Хранение в БД только пути к фотографии
- Получение перевала по id
- Редактирование перевала, если его статус "new"
- Получение списка перевалов по email пользователя

---

## Технологии

- Python
- Django
- Django REST Framework
- PostgreSQL
